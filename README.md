# Soccer Matches API

API REST para gerenciamento de partidas de futebol informal.

## 🚀 Tecnologias

- **Node.js** com **TypeScript**
- **ESLint** + **Prettier** para qualidade de código
- Configurações prontas para desenvolvimento

## 📦 Instalação

```bash
# Instalar dependências
npm install

# ou usando yarn
yarn install
```

## 🛠️ Scripts Disponíveis

```bash
# Executar verificações de código
npm test

# Desenvolvimento com watch mode
npm run dev

# Build para produção
npm run build

# Verificar qualidade do código
npm run lint
npm run format
```

## 📁 Estrutura do Projeto

```
.
├── src/                    # Código fonte da API
├── dist/                   # Build de produção
├── .eslintrc.js           # Configuração ESLint
├── .prettierrc            # Configuração Prettier
├── tsconfig.json          # Configuração TypeScript
└── package.json           # Dependências e scripts
```

## 🔧 Configuração

O projeto está configurado com:

- **TypeScript** com configurações modernas (ESNext, Node.js)
- **ESLint** com regras recomendadas
- **Prettier** para formatação automática
- **Source Maps** para debugging
- **Strict Mode** habilitado

## 📖 Desenvolvimento

1. Clone o repositório
2. Execute `npm install`
3. Inicie o desenvolvimento com `npm run dev`
4. A API estará disponível em `http://localhost:3000` (ou porta configurada)
