# Soccer Matches API

REST API for managing informal soccer matches (pickup games).

## 🚀 Technologies

- **Node.js** with **TypeScript**
- **ESLint** + **Prettier** for code quality
- Ready-to-use development configurations

## 📦 Installation

```bash
# Install dependencies
npm install

# or using yarn
yarn install
```

## 🛠️ Available Scripts

```bash
# Run code checks
npm test

# Development with watch mode
npm run dev

# Build for production
npm run build

# Check code quality
npm run lint
npm run format
```

## 📁 Project Structure

```
.
├── src/                    # API source code
├── dist/                   # Production build
├── .eslintrc.js           # ESLint configuration
├── .prettierrc            # Prettier configuration
├── tsconfig.json          # TypeScript configuration
└── package.json           # Dependencies and scripts
```

## 🔧 Configuration

The project is configured with:

- **TypeScript** with modern settings (ESNext, Node.js)
- **ESLint** with recommended rules
- **Prettier** for automatic formatting
- **Source Maps** for debugging
- **Strict Mode** enabled

## 📖 Development

1. Clone the repository
2. Run `npm install`
3. Start development with `npm run dev`
4. API will be available at `http://localhost:3000` (or configured port)

## 🎯 Features

Robust system to manage:
- ⚽ Informal soccer sessions
- 👥 Teams and players
- 📊 Real-time match events
- 📋 Configurable rules
- 📈 Detailed statistics
